Docker en macOS

Guía de instalación y primeros pasos

📋 Requisitos del sistema

Requisitos mínimos recomendados

  • macOS Big Sur (11) o superior (idealmente Monterey 12 o más reciente).
  • Procesador Intel de 64 bits o chip Apple Silicon (M1, M2, M3, etc.).
  • 4 GB de RAM (recomendado 8 GB o más).
  • Al menos 5 GB de espacio libre en disco.
  • Permisos de administrador para instalar aplicaciones.
Nota: En equipos administrados por una empresa o universidad, es posible que necesites que el área de TI apruebe o realice la instalación de Docker Desktop.

🧠 Paso 1: Verificar el tipo de chip del Mac

Antes de descargar Docker Desktop, es importante saber si tu Mac tiene procesador Intel o Apple Silicon.

  1. Haz clic en el ícono de la manzana  en la esquina superior izquierda.
  2. Selecciona "Acerca de esta Mac".
  3. En la ventana que aparece, revisa el campo "Chip" o "Procesador":
    • Si ves algo como "Chip Apple M1", M2, M3, es un Mac con Apple Silicon.
    • Si ves algo como "Intel Core i5" o similar, es un Mac con procesador Intel.
Docker ofrece instaladores separados para Mac con chip Intel y para Mac con Apple Silicon. Asegúrate de descargar el adecuado.

⬇️ Paso 2: Descargar Docker Desktop para Mac

Abre tu navegador y entra a la página oficial de Docker Desktop:

📥 Descargar Docker Desktop para Mac

En la página, selecciona la versión que corresponda a tu equipo:

  • Mac with Intel chip, si tu Mac usa procesador Intel.
  • Mac with Apple silicon, si tu Mac tiene chip M1, M2, M3, etc.
El archivo descargado será un paquete .dmg, con un nombre similar a: Docker.dmg o Docker Desktop Installer.dmg.

💿 Paso 3: Instalar Docker Desktop en macOS

1 Abrir el archivo .dmg

Busca el archivo descargado (en la carpeta Descargas) y haz doble clic para abrirlo.

Se abrirá una ventana con el ícono de Docker y la carpeta "Applications".
2 Arrastrar Docker a Applications

Arrastra el ícono de Docker.app hacia el ícono de Applications.

3 Ejecutar Docker por primera vez

Abre la carpeta Applications, busca Docker y haz doble clic. Es posible que macOS muestre un aviso para confirmar que quieres abrir una app descargada de internet.

La primera vez, macOS puede pedir tu contraseña de administrador y mostrar ventanas de permisos adicionales. Acepta estos permisos para que Docker Desktop pueda funcionar correctamente.

Después de unos segundos/minutos, deberías ver el ícono de la ballena de Docker en la barra superior (menú).

Cuando Docker termine de arrancar, mostrará el mensaje "Docker Desktop is running". En ese punto ya puedes usar el comando docker desde la Terminal.

🐋 Paso 4: Probar Docker con hello-world

Ahora vamos a comprobar que Docker funciona correctamente ejecutando un contenedor de prueba.

$ docker --version
Docker version XX.XX.X, build XXXXXXX

Si ves una versión similar, Docker está instalado. Ejecuta ahora el contenedor de prueba:

$ docker run hello-world
Si todo sale bien, verás un mensaje indicando que Docker descargó la imagen hello-world y que el contenedor se ejecutó correctamente.

🧪 Comandos básicos de Docker

Algunos comandos útiles para empezar:

Ver imágenes descargadas

docker images

Muestra las imágenes que tienes en tu máquina.

Ver contenedores en ejecución

docker ps

Lista solo los contenedores activos.

Ver todos los contenedores

docker ps -a

Incluye los que ya se detuvieron.

Eliminar contenedor

docker rm NOMBRE_O_ID

Elimina un contenedor que ya no necesites.

🌐 Ejemplo rápido con Nginx

Como ejemplo sencillo, vamos a levantar un servidor web Nginx en un contenedor.

1 Descargar y ejecutar Nginx
$ docker run -d -p 8080:80 --name mi-web nginx
2 Probar en el navegador
Abre tu navegador y visita:
http://localhost:8080

Deberías ver la página de bienvenida de Nginx: "Welcome to nginx!" 🎉

⚙️ Ajustar recursos de Docker Desktop

Si notas que el Mac se vuelve lento al usar contenedores pesados, puedes ajustar cuánta CPU y memoria puede usar Docker.

  1. Abre Docker Desktop.
  2. Haz clic en el ícono de engranaje (⚙️) para abrir Preferences.
  3. Ve a la sección Resources.
  4. Ajusta CPU y Memory según las capacidades de tu equipo.
Como regla general, puedes asignar a Docker aproximadamente la mitad de la RAM y de los núcleos de CPU de tu máquina, dejando el resto para el sistema y otras aplicaciones.
