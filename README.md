# 📦 Capacitación de Docker

Este repositorio reúne el material de una capacitación introductoria en Docker.
La idea es ofrecer una primera aproximación al uso de contenedores, combinando explicación teórica, demostraciones y un ejercicio práctico sencillo.

## Objetivo general

Diseñar una capacitación básica de Docker que permita a cualquier persona dar sus primeros pasos con esta herramienta, entendiendo sus conceptos clave y viendo un ejemplo práctico de contenedorización de una aplicación.

## Objetivos específicos

Al finalizar la capacitación se espera que la persona participante:

- Tenga una idea clara de qué son las imágenes y los contenedores en Docker.
- Entienda en qué se diferencian los contenedores de las máquinas virtuales.
- Conozca el flujo general para instalar Docker y realizar una primera prueba.
- Vea ejemplos de comandos básicos de Docker y sus resultados.
- Revise un caso práctico donde se construye una imagen a partir de un `Dockerfile` y se ejecuta una aplicación dentro de un contenedor.

## Contenidos generales de la capacitación

La capacitación se organiza en tres bloques principales:

1. **Introducción a Docker**  
   - Motivación: por qué se usan contenedores.  
   - Conceptos básicos: imagen, contenedor, Docker Engine, Docker Hub.  
   - Comparación general entre contenedores y máquinas virtuales.

2. **Instalación y primeros pasos**  
   - Idea general del proceso de instalación de Docker.  
   - Ejemplo de ejecución de contenedores de prueba.  
   - Comentario sobre algunos comandos básicos (`docker run`, `docker ps`, `docker images`, entre otros).

3. **Ejercicio práctico guiado**  
   - Presentación de una aplicación sencilla como ejemplo.  
   - Revisión de un `Dockerfile` básico.  
   - Construcción de una imagen y ejecución de la aplicación en un contenedor.  
   - Acceso a la aplicación desde el navegador usando `localhost`.

## Metodología

La capacitación combina:

- Explicación teórica apoyada en una presentación.
- Demostraciones paso a paso.
- Un ejercicio práctico que sirve para aterrizar los conceptos en un ejemplo realista pero manejable.

## Público objetivo

Esta capacitación está pensada para personas que:

- No tienen experiencia previa con Docker o solo han escuchado el concepto.
- Quieren entender la idea general de los contenedores antes de entrar a temas más avanzados.
